# CSV分析工具集

这个工具集用于分析各种CSV数据文件，提取重要信息并生成统计结果。当前包含多种分析方法，所有分析脚本默认会批量处理CSV文件夹中的数据文件。

## 目录结构

```
analysis_scripts/
├── analyze_csv_Sig1Ins/                # Sig1Ins分析工具目录
│   ├── analyze_csv_Sig1Ins.py          # 单文件分析工具
│   └── analyze_csv_Sig1Ins_batch.py    # 批量处理CSV文件的脚本
├── analyze_Sig1_result_dist/           # Sig1与result分布关系分析工具目录
│   ├── sig1_result_distribution.py     # 单文件分布分析工具
│   └── sig1_result_distribution_batch.py # 批量处理并合并结果的脚本
├── CSV/                                # 数据文件夹，存放待分析的CSV文件
└── README.md                           # 本文档
```


## 添加新的分析方法

如需添加新的分析方法，建议遵循以下规范:

1. **创建独立目录**: 在`analysis_scripts`下创建新的子目录，以分析方法名称命名
2. **实现两个级别的脚本**:
   - 单文件分析脚本: 处理单个CSV文件的核心功能
   - 批处理脚本: 批量处理CSV目录下的所有CSV文件

3. **标准化参数**: 
   - 使用`argparse`解析命令行参数
   - 默认从`../CSV`目录读取输入文件
   - 提供指定输入/输出路径的选项

4. **文档规范**:
   - 在脚本顶部添加文件说明注释
   - 为每个函数添加文档字符串，说明参数和返回值
   - 在目录中添加README.md描述该分析方法

5. **异常处理**:
   - 检查文件存在性和列的有效性
   - 处理可能的异常，提供有意义的错误消息
   - 批处理脚本应在单个文件失败时继续处理其他文件

6. **输出标准化**:
   - 结果保存在固定的输出目录中（如`results/`）
   - 使用明确的命名约定（如`文件名_分析类型.csv`）
   - 提供适当的进度和结果摘要输出

## 依赖

- Python 3.6+
- pandas (数据处理)
- matplotlib (可视化，部分脚本需要)
- seaborn (热图生成，部分脚本需要)
- tqdm (进度显示，部分脚本需要)
