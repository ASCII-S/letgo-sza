## 功能概述

手动指令注错功能允许你在 `configure.py` 中直接指定要注错的指令位置、执行时刻和注错次数，无需修改自动生成的 pool 文件。

### 主要特性

- ✅ **配置集中化**：所有配置在 `configure.py` 中管理
- ✅ **灵活控制**：精确指定注错位置、时刻和次数
- ✅ **自动管理**：自动生成 pool 文件并备份旧文件
- ✅ **格式兼容**：与自动生成的 pool 格式完全兼容
- ✅ **易于切换**：通过开关快速切换手动/自动模式

## 快速开始

### 步骤 1：启用手动注错模式

在 `configure.py` 中设置：

```python
# 确保是 targeted 模式
inject_random_or_targeted = "targeted"

# 启用手动指令注错
use_manual_instructions = True
```

### 步骤 2：配置注错指令

在 `configure.py` 中添加配置：

```python
manual_instructions = [
    ["rdx", "", "0x467c2b", 1023, 100],  # 对该指令注错 100 次
]
```

### 步骤 3：运行实验

```bash
python letgo_wrapper.py
```

系统会自动：
1. 备份旧的 pool 文件（如 `mov_pool.csv.backup`）
2. 生成新的手动 pool 文件（覆盖 `mov_pool.csv`）
3. 开始注错实验

## 配置详解

### 配置格式

每条配置使用 5 参数格式：

```python
[regmem, reg, pc_hex, max_iteration, repeat_count]
```

### 参数说明表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `regmem` | string | ✅ | - | 内存操作数寄存器（如 `"rbp"`），无则填 `""` |
| `reg` | string | ✅ | - | 目标寄存器（如 `"rax"`），无则填 `""` |
| `pc_hex` | string | ✅ | - | 指令地址（十六进制），支持 `"0x4026b1"` 或 `"4026b1"` |
| `max_iteration` | int | ❌ | 1023 | 该指令在程序中的最大执行次数 |
| `repeat_count` | int | ❌ | 1 | 对该位置重复注错的次数 |

### 参数详解

#### 1. regmem 和 reg

从 catalog 文件的前两列获取：

```
rbp,,4026b1,MOV,mov eax, dword ptr [rbp-0x1c],12474
^^^  ^^
regmem reg
```

- `regmem`：内存操作数寄存器（如 `rbp`）
- `reg`：目标寄存器（如果没有则为空）

#### 2. pc_hex

指令地址，从 catalog 文件的第三列获取：

```
rbp,,4026b1,MOV,mov eax, dword ptr [rbp-0x1c],12474
     ^^^^^^
     pc_hex
```

支持两种格式：
- 带前缀：`"0x4026b1"`
- 不带前缀：`"4026b1"`

#### 3. max_iteration

该指令在程序执行过程中被执行的最大次数，从 catalog 文件的最后一列获取：

```
rbp,,4026b1,MOV,mov eax, dword ptr [rbp-0x1c],12474
                                               ^^^^^
                                               max_iteration
```

**作用**：限制 iteration 的最大值，防止超出指令实际执行次数。

**示例**：
- 如果 `max_iteration=10`，`repeat_count=100`
- 生成 100 条记录，但 iteration 只到 10
- 前 11 条：iteration = 0, 1, 2, ..., 10
- 后 89 条：iteration = 10（保持不变）

#### 4. repeat_count

对该指令位置重复注错的次数。

**iteration 分配规则**：
- 从 0 开始递增：0, 1, 2, 3, ...
- 不超过 `max_iteration`
- 生成 `repeat_count` 条记录

## 参数说明

### iteration 的含义

`iteration` 表示：**在程序执行过程中，该 PC 地址第几次被执行时触发注错**

#### 示例

假设程序中有一个循环：

```c
for (int i = 0; i < 100; i++) {
    x = x + 1;  // PC 地址：0x4026b1
}
```

这条指令会被执行 100 次：

- `iteration=0` → 在**第 1 次**执行时注错
- `iteration=5` → 在**第 6 次**执行时注错
- `iteration=99` → 在**第 100 次**执行时注错

### 如何获取 max_iteration

#### 方法 1：从 catalog 文件获取（推荐）

1. 运行一次自动目标注错，生成 catalog 文件：

```bash
# 在 configure.py 中设置
use_manual_instructions = False  # 先关闭手动模式
inject_random_or_targeted = "targeted"
select_type = "mov"

# 运行生成 catalog
python letgo_wrapper.py
```

2. 查看 catalog 文件：

```bash
head -10 TargetedBenchmarkResult/fdtd-2d/mov/mov_catalog.csv
```

输出示例：
```
rbp,,4026b1,MOV,mov eax, dword ptr [rbp-0x1c],12474
rbp,,402605,MOV,mov eax, dword ptr [rbp-0x24],12096
rdx,,402678,MOVSD_XMM,movsd xmm0, qword ptr [rdx+rax*8],12096
```

3. 最后一列就是 `max_iteration`

#### 方法 2：使用默认值

如果不确定 `max_iteration`，可以使用默认值 `1023`：

```python
manual_instructions = [
    ["rdx", "", "0x467c2b", 1023, 100],  # 使用默认值
]
```

## 常见问题

### Q1：为什么 pool 文件是空的？

**原因**：配置格式错误，使用了 4 参数格式。

**错误示例**：
```python
manual_instructions = [
    ["rdx", "", "0x467c2b", 100],  # ❌ 错误！
]
```

这会被解析为：
- `max_iteration = 100`
- `repeat_count = 1`（默认）

结果：只生成 1 条记录，第一次实验就用完了。

**正确示例**：
```python
manual_instructions = [
    ["rdx", "", "0x467c2b", 1023, 100],  # ✅ 正确！
]
```

### Q2：如何知道配置是否正确？

运行前测试：

```bash
python -c "
import configure
import InstPoolMaker

print('配置:', configure.manual_instructions)
pool_path = InstPoolMaker.generate_manual_pool(pool_csv_file='/tmp/test_pool.csv')
print('\n生成的 pool 行数:')
import subprocess
subprocess.run(['wc', '-l', '/tmp/test_pool.csv'])
"
```

### Q3：如何查看生成的 pool 内容？

```bash
# 查看前 10 行
head -10 TargetedBenchmarkResult/fdtd-2d/mov/mov_pool.csv

# 查看后 10 行
tail -10 TargetedBenchmarkResult/fdtd-2d/mov/mov_pool.csv

# 查看总行数
wc -l TargetedBenchmarkResult/fdtd-2d/mov/mov_pool.csv
```

### Q4：旧的 pool 文件去哪了？

自动备份到 `.backup` 文件：

```bash
ls -lh TargetedBenchmarkResult/fdtd-2d/mov/mov_pool.csv*
```

输出：
```
mov_pool.csv         # 新的手动 pool
mov_pool.csv.backup  # 旧的自动 pool（备份）
```

### Q5：如何切换回自动模式？

在 `configure.py` 中设置：

```python
use_manual_instructions = False
```

系统会自动回退到原有的自动生成 pool 流程。

### Q6：可以混合使用手动和自动模式吗？

不可以。两种模式是互斥的：
- `use_manual_instructions = True` → 手动模式
- `use_manual_instructions = False` → 自动模式

### Q7：如何验证注错是否生效？

查看日志文件：

```bash
grep "args ready" TargetedBenchmarkResult/fdtd-2d/mov/log/log_0
```

输出示例：
```
args ready for set breakpoint:   ['rdx', '', '4619307', '0']
```

- `4619307` 是十进制地址（对应 `0x467c2b`）
- `0` 是 iteration

## 高级用法

### 1. 批量配置

使用 Python 列表推导式生成配置：

```python
# 对同一个指令的不同 iteration 注错
manual_instructions = [
    ["rbp", "", "0x4026b1", 12474, 100],  # iteration 0-99
    ["rbp", "", "0x4026b1", 12474, 100],  # 可以重复配置
]
```

### 2. 从文件读取配置

```python
# 在 configure.py 中
import csv

def load_manual_instructions(csv_file):
    """从 CSV 文件加载手动注错配置"""
    instructions = []
    with open(csv_file, 'r') as f:
        reader = csv.reader(f)
        for row in reader:
            if len(row) >= 5:
                instructions.append([
                    row[0],           # regmem
                    row[1],           # reg
                    row[2],           # pc_hex
                    int(row[3]),      # max_iteration
                    int(row[4])       # repeat_count
                ])
    return instructions

# 使用
manual_instructions = load_manual_instructions('my_instructions.csv')
```

### 3. 动态生成配置

```python
# 根据 catalog 自动生成配置
def generate_from_catalog(catalog_file, repeat_count=100):
    """从 catalog 文件生成手动配置"""
    instructions = []
    with open(catalog_file, 'r') as f:
        for line in f:
            parts = line.strip().split(',')
            if len(parts) >= 6:
                regmem = parts[0]
                reg = parts[1]
                pc_hex = "0x" + parts[2]
                max_iteration = int(parts[5])
                instructions.append([regmem, reg, pc_hex, max_iteration, repeat_count])
    return instructions

# 使用
# manual_instructions = generate_from_catalog(
#     'TargetedBenchmarkResult/fdtd-2d/mov/mov_catalog.csv',
#     repeat_count=100
# )
```

### 4. 条件过滤

只选择特定类型的指令：

```python
# 只选择 MOV 指令
def filter_mov_instructions(catalog_file, repeat_count=100):
    instructions = []
    with open(catalog_file, 'r') as f:
        for line in f:
            parts = line.strip().split(',')
            if len(parts) >= 6 and 'MOV' in parts[3]:
                regmem = parts[0]
                reg = parts[1]
                pc_hex = "0x" + parts[2]
                max_iteration = int(parts[5])
                instructions.append([regmem, reg, pc_hex, max_iteration, repeat_count])
    return instructions
```

```python

# 1. 启用手动模式
use_manual_instructions = True

```
[regmem, reg, pc_hex, max_iteration, repeat_count]
 ^^^^^^  ^^^  ^^^^^^  ^^^^^^^^^^^^^  ^^^^^^^^^^^^
