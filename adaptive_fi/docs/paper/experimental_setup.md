## 2 SDC评判标准

在故障注入实验中，正确区分静默数据损坏（SDC）与被掩蔽（Masked）的故障是评估应用程序可修复性的关键前提。SDC评判的核心思路是将故障注入后的程序输出与预先采集的无故障基准输出（Golden Output）进行比较，根据应用的计算语义和输出的物理含义确定合理的正确性判定准则。

### 2.1 确定性离散输出类应用

对于计算结果为确定性离散值的应用，其输出在相同输入条件下具有唯一确定的正确答案，任何位级偏差都意味着计算错误的发生。

**BFS（广度优先搜索）。** 该应用输出从源顶点到图中每个顶点的最短距离数组，距离值以边数计量。由于图结构和源顶点固定，每个顶点的距离是唯一确定的非负整数。若故障导致任意顶点的距离值发生改变，则表明图遍历过程出现错误，应判定为SDC。因此，采用逐字节精确比较，要求输出与基准完全一致方可判定为Masked。

**Backprop（反向传播神经网络）。** 该应用输出训练后的神经网络权重矩阵，每个权重值代表相邻神经元层之间的连接强度。由于训练过程采用固定的随机种子初始化，相同的训练数据应产生完全相同的权重参数。神经网络对权重扰动极为敏感，即使最低有效位的变化也可能在后续推理中被逐层放大，导致分类或预测结果的偏差。因此，采用精确比较验证权重矩阵的一致性。

**K-Means（K均值聚类）。** 该应用输出包含聚类标签分配和聚类中心坐标。聚类标签为离散整数，表示每个数据点所属的簇；聚类中心为迭代收敛后的确定值。由于采用固定初始化策略，相同输入应收敛到相同的聚类结果，采用精确比较。

**NN（最近邻搜索）和Particle Filter（粒子滤波）。** 类似地，这两个应用的输出分别为最近邻索引/距离和粒子状态估计，均采用确定性算法在固定输入下产生唯一输出，故采用精确比较。

### 2.2 物理场模拟类应用

对于求解偏微分方程的物理场模拟应用，其输出为离散化网格上的物理量分布。由于数值求解过程涉及浮点迭代和舍入运算，允许存在微小的数值误差，但误差应控制在物理意义可接受的范围内。

**Hotspot（处理器热分布模拟）。** 该应用求解二维热传导方程，输出芯片各网格点的温度值（单位：开尔文）。温度场反映了功耗分布导致的热量传导平衡状态，是处理器热管理设计的关键依据。考虑到热传导方程数值解的精度特性，设定绝对容差$\epsilon = 10^{-6}$ K。即对于任意网格点$(i,j)$，若故障注入后的温度值$T_{i,j}$与基准值$\hat{T}_{i,j}$满足$|T_{i,j} - \hat{T}_{i,j}| \leq 10^{-6}$，则判定该点计算正确；当且仅当所有网格点均满足该条件时，判定为Masked。

**SRAD（各向异性扩散滤波）。** 该应用基于偏微分方程进行图像去噪处理，输出滤波后的像素强度矩阵。由于图像处理对绝对精度要求相对宽松，设定绝对容差$\epsilon = 0.1$，在此范围内的像素值偏差不影响视觉效果和后续图像分析。

**FDTD-2D（二维时域有限差分）。** 该应用模拟电磁波在二维空间的传播，输出各网格点的电场和磁场分量。电磁场值的量级跨度较大，采用相对误差判定更为合理，设定相对容差$\epsilon_{rel} = 0.1$。即对于场分量$E$，当$|E_{test} - E_{golden}|/|E_{golden}| \leq 0.1$时判定为正确。

### 2.3 迭代求解器类应用

迭代求解器通过逐步逼近的方式求解线性方程组$\mathbf{Ax} = \mathbf{b}$，其核心输出指标为残差范数$\|\mathbf{r}\| = \|\mathbf{b} - \mathbf{Ax}\|$。残差范数直接度量当前迭代解与真实解的偏离程度，是评判求解器收敛性和求解精度的关键指标。任何计算过程中的错误都会影响迭代轨迹，导致最终残差偏离预期值，这一特性使得残差范数成为SDC检测的天然指示器。

**AMG（代数多重网格求解器）。** AMG通过多重网格V循环加速大规模稀疏线性系统的收敛。应用输出的关键指标为最终相对残差范数（Final Relative Residual Norm），定义为$\|\mathbf{r}\|/\|\mathbf{b}\|$，正常求解应收敛至$10^{-9}$量级。SDC评判时，比较故障注入后的残差范数$r_{test}$与基准残差范数$r_{golden}$的相对偏差，当$|r_{test} - r_{golden}|/|r_{golden}| \leq 10^{-6}$时判定为Masked。若残差明显偏离（如量级变化或发散），则表明多重网格迭代过程受到故障干扰。

**HPCCG（共轭梯度法）。** 该Mantevo微型应用采用预条件共轭梯度法求解稀疏对称正定系统。共轭梯度法具有理论上$n$步收敛的性质，其输出的最终残差（Final Residual）反映求解精度。设定绝对容差$\epsilon = 10^{-6}$，当$|r_{test} - r_{golden}| \leq 10^{-6}$时判定为Masked。

**MiniFE（有限元微型应用）。** MiniFE模拟隐式有限元计算流程，内部采用共轭梯度法求解离散化后的线性系统。其输出的最终残差范数（Final Resid Norm）具有与HPCCG相同的物理含义，采用相同的绝对容差$\epsilon = 10^{-6}$进行判定。

**NPB-CG和NPB-MG。** NPB套件中的CG（共轭梯度）和MG（多重网格）应用分别代表两类主流迭代求解方法，其SDC判定机制将在2.5节与其他NPB应用一并说明。

### 2.4 矩阵分解与线性代数核心

**LU矩阵分解。** LU分解将矩阵$\mathbf{A}$分解为下三角矩阵$\mathbf{L}$和上三角矩阵$\mathbf{U}$的乘积，即$\mathbf{A} = \mathbf{LU}$。分解结果的正确性验证基于矩阵乘法的还原：从输出中提取$\mathbf{L}$和$\mathbf{U}$矩阵，计算乘积$\mathbf{L} \times \mathbf{U}$，与原始矩阵$\mathbf{A}$逐元素比较。考虑到浮点运算的累积误差，设定绝对容差$\epsilon = 10^{-4}$。若任意元素满足$|(\mathbf{LU})_{ij} - \mathbf{A}_{ij}| > 10^{-4}$，则判定为SDC。

**HPL（高性能Linpack基准）。** HPL是衡量超级计算机浮点运算能力的标准基准测试，通过LU分解法求解稠密线性方程组$\mathbf{Ax} = \mathbf{b}$。HPL采用国际公认的缩放残差（Scaled Residual）作为正确性判据：

$$r = \frac{\|\mathbf{Ax} - \mathbf{b}\|_\infty}{\epsilon_m \cdot (\|\mathbf{A}\|_\infty \cdot \|\mathbf{x}\|_\infty + \|\mathbf{b}\|_\infty) \cdot N}$$

其中$\epsilon_m$为机器精度（双精度浮点约为$2.2 \times 10^{-16}$），$N$为问题规模。该公式通过归一化消除了问题规模和条件数的影响。根据HPL规范，当$r < 16.0$时判定计算正确（PASSED）。SDC评判时同时检查缩放残差值和PASSED状态标志，两个条件均满足时方可判定为Masked。

**PolyBench线性代数核心。** PolyBench/C套件中的应用代表了编译器优化研究中的典型计算核心。2MM输出两次矩阵乘法的结果矩阵$\mathbf{D} = \mathbf{AB} \cdot \mathbf{C} + \mathbf{D}$；BiCG输出双共轭梯度法的中间向量；GESUMMV输出向量$\mathbf{y} = \alpha\mathbf{Ax} + \beta\mathbf{Bx}$；SYR2K输出对称秩2k更新后的矩阵。由于这些核心的输出矩阵/向量元素量级跨度较大，统一采用相对误差判定，设定相对容差$\epsilon_{rel} = 0.1$。对于Correlation（相关系数矩阵），由于相关系数本身已归一化至$[-1, 1]$区间，相对误差判定同样适用。

### 2.5 内置自验证机制

NAS Parallel Benchmarks设计之初即内置了完整的数值验证机制，每个应用在运行结束时自动进行结果校验并报告验证状态。这一特性为SDC判定提供了便利。

NPB各应用在计算完成后，将数值解的均方根范数（RMS-norms）与预存的参考值进行比较，格式为：

```
Comparison of RMS-norms of residual
    1  0.1703428370954E+00  0.1703428370954E+00  0.7201925617357E-13
    2  0.1297525207003E-01  0.1297525207003E-01  0.3680617304070E-12
```

其中三列分别为：计算值、参考值、相对误差。若所有维度的相对误差均不超过精度阈值$\epsilon = 10^{-7}$，则输出"Verification Successful"。

**BT和SP（块/标量对角矩阵求解器）。** 这两个应用模拟三维可压缩Navier-Stokes方程的数值解，分别采用块三对角和标量五对角矩阵求解方案。其RMS范数涵盖速度场、压力场等物理量的统计特征。

**LU（高斯-赛德尔求解器）。** 该NPB应用采用对称高斯-赛德尔迭代法求解类似的CFD问题，验证机制与BT/SP一致。

**FT（快速傅里叶变换）。** 验证三维FFT变换的频谱精度，RMS范数反映变换后复数数组的统计特性。

**EP（统计计算）。** 验证高斯随机数生成的统计量，包括均值、方差等参数是否落在理论预期范围内。

**IS（整数排序）。** 验证排序后的数组是否满足单调性和完整性约束。

**UA（非结构化自适应网格）。** 验证自适应网格细化后的数值解精度。

SDC评判流程为：首先从程序输出中提取验证状态字段；若为"Successful"，进一步检查各RMS范数的相对误差是否均不超过$10^{-7}$；若状态为"Unsuccessful"或无法提取（如程序异常终止），直接判定为SDC。

### 3.3 故障注入方法

本文的故障注入实验基于Intel Pin动态二进制插桩框架实现。Pin是Intel公司开发的动态二进制插桩工具，能够在程序运行时对其二进制指令进行插桩分析和修改，而无需重新编译源代码。故障注入过程中，通过Pin工具在目标应用的指令执行过程中，对指定寄存器或内存位置进行单比特翻转（Single-Bit Flip），模拟瞬态硬件故障（如宇宙射线引起的软错误）对程序执行的影响。

每次故障注入实验的结果被归类为以下四种类型之一：

- **Masked（掩蔽）**：程序正常完成且输出与基准输出在容差范围内一致，表明注入的故障被程序的自然计算过程所掩蔽。
- **SDC（静默数据损坏）**：程序正常完成但输出与基准输出存在超出容差范围的偏差，表明故障导致了不可察觉的计算结果错误。
- **Crash（崩溃）**：程序因故障注入而异常终止，包括段错误、非法指令异常等。
- **Hang（挂起）**：程序因故障注入而陷入死循环或长时间无响应，超过预设的超时阈值后被强制终止。
